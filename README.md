# 📊 Student Performance Analytics Dashboard

A simple and interactive dashboard built using Python and Streamlit to analyze student academic performance.

## About the Project

The Student Performance Analytics Dashboard helps users understand student performance through marks analysis, interactive filters, charts, and grade distribution.

## Features

- View student records.
- Filter students by gender.
- Calculate average marks.
- Analyze pass and fail results.
- View subject-wise average performance.
- Visualize grade distribution.
- Upload custom CSV files.
- Validate uploaded student data.

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib

## How to Run the Project

1. Install Python.
2. Install the required libraries:

```bash
pip install streamlit pandas matplotlib
```

3. Run the application:

```bash
streamlit run app.py
```

## Dataset

The project uses student marks in Math, Science, English, and Computer subjects.
